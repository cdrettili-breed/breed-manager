NIIMBOT B1で印刷

このページは Bluefy（Bluetooth対応ブラウザ）で開いてください。Safariやホーム画面のアプリからはB1につなげません。
プリンター:未接続
B1が一覧に出てこないとき
  1. NIIMBOTアプリを完全に終了してください（アプリ切り替え画面で上にスワイプ）。B1は他のアプリとつながっている間、一覧に出てきません。
  2. B1の電源を入れ直し、ランプが点いてから「近くの機器からB1を選んでつなぐ」を押してください。
  3. iPhoneの「設定 → Bluetooth」でB1が「接続済み」なら、ⓘ →「このデバイスの登録を解除」を押してください。
  4. 「設定 → アプリ → Bluefy」でBluetoothがオンか確認してください。

Breed Managerで「印刷」を押すとラベルがコピーされます。このページに戻って、上のボタンを押してください（「ペースト」の確認が出たら許可）。

貼り付けがうまくいかないとき

下の枠を長押しして「ペースト」してから、上のボタンを押してください。

印刷が横向きや切れて出るときは「向き」を変えてください。設定はこのブラウザに保存されます。
